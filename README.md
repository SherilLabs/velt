# VAULT — Personal Savings Tracker

A local-first savings dashboard built with HTML, CSS, JavaScript, Chart.js and localStorage.

## Run locally
1. Extract the ZIP.
2. Open the `vault-savings-tracker` folder in VS Code.
3. Open `index.html` with Live Server (recommended), or open the file in a browser.
4. Internet is required to load Chart.js, Lucide icons, and Google Fonts from their CDNs.

## Features
- Overview cards and charts
- Add/edit/delete transactions
- Search and category/type filters
- Saving goals with progress
- Calendar with transaction details by date
- Insights and monthly recap
- JSON backup/restore and CSV export
- Responsive layout and localStorage persistence

## Important
- Data stays in this browser profile on this device; it does not sync across devices.
- Export JSON backups regularly. Restoring a backup replaces current data.
- Do not store bank PINs, passwords, or other highly sensitive credentials here.
- This is a personal record-keeping tool, not a bank account or financial advice tool.
