Data & backup.

Unduh semua transaksi dan target sebagai file JSON. Gunakan file ini untuk memulihkan data nanti.

Restore backup

Impor file backup VAULT yang sebelumnya kamu ekspor. Data yang ada akan diganti dengan data dari file tersebut.

Hapus semua transaksi dan target dari browser ini. Tindakan ini tidak bisa dibatalkan kecuali kamu punya backup.

Privacy note
